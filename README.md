# CV Web

Personal portfolio and curriculum vitae website for Silvia Beut, built as a responsive static web page to showcase education, work experience, skills, and projects.

## Overview

This project is a single-page portfolio website designed to present:

- Educational background
- Professional experience
- Technical skills and personal interests
- Project examples
- Contact form for inquiries

The site combines HTML, CSS, and JavaScript to create a clean, modern interface with interactive navigation and form validation.

## Project structure

```text
CV-web/
├── index.html          # Main landing page / CV
├── projects.html       # Additional project detail page
├── style.css           # Main styling and responsive layout
├── script.js           # Form validation and menu behavior
├── imgs/               # Project and profile images
├── webfonts/           # Custom font files
└── README.md           # Project documentation
```

## Features

- Responsive layout for desktop and mobile devices
- Navigation menu with smooth section access
- Portfolio section with project previews
- Contact form with client-side validation
- Modern typography and styling using external font services

## Tech stack

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Google Fonts

## How to run locally

Because this is a static website, there is no installation or build process required.

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Alternatively, serve the folder with a local web server if preferred.

Example using Python:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

- The site is designed as a personal online CV and portfolio.
- It includes a contact form that submits to a third-party service (`staticforms.dev`).
- The visual design and content are tailored to the profile of Silvia Beut.
